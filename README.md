# Bootstrap Pricing Page

A clean and responsive pricing page built using **Bootstrap**.  
This project showcases a simple pricing layout with multiple subscription plans, suitable for SaaS or product websites.

## 🚀 Features
- Responsive design
- Built with Bootstrap
- Clean and minimal UI
- Three pricing tiers
- Mobile-friendly layout

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap
